We introduce FlashKV, a runtime that combines paging and compression of the key-value (KV) cache for long-context LLM serving. We evaluate FlashKV with Llama-3-70B on one node with eight H100 GPUs (Table 2). Across 4k to 32k contexts, FlashKV reduces KV-cache memory by 55% to 63% relative to vLLM, with decoding speedups increasing to 1.87x at 32k. At 64k, FlashKV supports serving while vLLM runs out of memory.
