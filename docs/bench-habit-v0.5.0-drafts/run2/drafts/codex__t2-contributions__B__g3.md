We introduce FlashKV, a runtime that combines KV-cache paging and compression to reduce memory use for long-context LLM serving. Our evaluation uses Llama-3-70B on one node with eight H100 GPUs (Table 2). Across the tested context lengths, FlashKV more than halves KV-cache memory use. Decoding speedup over vLLM grows with context length, from 1.10x at 4k tokens to 1.87x at 32k tokens. FlashKV also serves 64k-token contexts, where vLLM runs out of memory.
