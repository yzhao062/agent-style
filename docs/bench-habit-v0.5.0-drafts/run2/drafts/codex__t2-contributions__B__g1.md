We introduce FlashKV, a runtime that pages and compresses the key-value (KV) cache for long-context large language model serving. On Llama-3-70B running on one node with eight H100 GPUs, FlashKV reduces KV-cache memory by 55% to 63% relative to vLLM (Table 2). Decoding speedups increase with context length, from 1.10× at 4k to 1.87× at 32k. FlashKV also serves 64k contexts, where vLLM runs out of memory.
