We introduce FlashKV, a runtime that pages and compresses the key-value (KV) cache for long-context serving of large language models. On one node with eight H100 GPUs, FlashKV reduces KV-cache memory use for Llama-3-70B by 55% to 63% compared with vLLM (Table 2). At context lengths of 4k to 32k tokens, it accelerates decoding by 1.10x to 1.87x. FlashKV also serves 64k-token contexts, where vLLM runs out of memory.
