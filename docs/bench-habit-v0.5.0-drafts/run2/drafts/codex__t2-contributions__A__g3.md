We introduce FlashKV, a runtime that pages and compresses the key-value (KV) cache for long-context serving of large language models. On one node with eight H100 GPUs, FlashKV reduces KV-cache memory by 55% to 63% for Llama-3-70B across contexts of 4k to 64k tokens (Table 2). For contexts of 4k to 32k tokens, FlashKV speeds up decoding by 1.10x to 1.87x over vLLM. It also serves 64k-token contexts on the same node, where vLLM runs out of memory.
