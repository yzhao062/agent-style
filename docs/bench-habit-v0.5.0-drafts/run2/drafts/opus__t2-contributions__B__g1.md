This paper makes two contributions. First, we present FlashKV, a long-context LLM serving runtime that pages and compresses the KV cache so that GPU memory holds longer contexts. Second, we evaluate FlashKV against vLLM, serving Llama-3-70B on one 8xH100 node at context lengths from 4k to 64k tokens (Table 2). FlashKV reduces KV-cache memory by 55% to 63% across all four lengths. Its decoding speedup grows with context length, from a small 1.10x at 4k to 1.87x at 32k. At 64k, vLLM runs out of memory, while FlashKV continues to serve the model on the same node.
