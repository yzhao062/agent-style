This paper contributes FlashKV, a runtime that pages and compresses the KV cache for long-context LLM serving, together with an evaluation against vLLM. Table 2 reports results on Llama-3-70B using one 8xH100 node at context lengths from 4k to 64k. FlashKV reduces KV-cache memory by 55% to 63% across these lengths. Where both systems run, the decoding speedup over vLLM grows with context length, from 1.10x at 4k to 1.48x at 16k and 1.87x at 32k. At 64k, vLLM runs out of memory, while FlashKV still completes decoding.
