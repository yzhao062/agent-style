This paper makes two contributions. First, we present FlashKV, a runtime for long-context LLM serving that pages the KV cache and compresses it, which shrinks the GPU memory each request holds. Second, we compare FlashKV with vLLM by serving Llama-3-70B on one node with eight H100 GPUs at context lengths from 4k to 64k tokens (Table 2). FlashKV reduces KV-cache memory by 55% at 4k tokens and by 63% at 32k and 64k tokens. Its decoding speedup over vLLM is small at 4k tokens (1.10x) and grows with context length to 1.87x at 32k tokens. At 64k tokens, vLLM runs out of memory on the same node, while FlashKV continues to serve the model.
