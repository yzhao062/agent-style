We present FlashKV, a runtime for long-context LLM serving that pages and compresses the key-value (KV) cache, the per-token attention state that grows linearly with context length. Our evaluation compares FlashKV with vLLM on Llama-3-70B using one 8xH100 node. From 4k to 32k tokens, FlashKV reduces KV-cache memory by 55% to 63% and speeds up decoding by 1.10x to 1.87x (Table 2). Both gains are smallest at 4k tokens and grow with context length. At 64k tokens, vLLM runs out of memory, and FlashKV still serves the model.
