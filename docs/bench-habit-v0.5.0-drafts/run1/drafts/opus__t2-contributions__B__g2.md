This paper makes two contributions. First, we present FlashKV, a runtime for long-context LLM serving that manages the KV cache in pages and compresses those pages. Second, we evaluate FlashKV against vLLM by serving Llama-3-70B on one node of eight H100 GPUs at context lengths from 4k to 64k tokens (Table 2). FlashKV uses 55% to 63% less KV-cache memory than vLLM, and its decoding speedup grows with context length, from 1.10× at 4k tokens to 1.87× at 32k. At 64k tokens, where vLLM runs out of memory, FlashKV still serves requests on the same node.
