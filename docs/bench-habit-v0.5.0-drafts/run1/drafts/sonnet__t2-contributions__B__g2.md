We introduce FlashKV, a runtime that pages and compresses the key-value (KV) cache for long-context large language model (LLM) serving. The KV cache holds the per-token attention state that a model keeps in GPU memory while decoding. Compared with vLLM on Llama-3-70B with one 8xH100 node, FlashKV cuts KV-cache memory by 55% at 4k tokens of context and by 63% at 32k. Decoding speedup grows with context length, from 1.10x at 4k to 1.87x at 32k (Table 2). At 64k tokens, vLLM runs out of memory on the same node, and FlashKV still runs.
