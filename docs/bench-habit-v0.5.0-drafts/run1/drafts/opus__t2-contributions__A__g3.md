This paper makes two contributions. First, we design and implement FlashKV, a serving runtime that pages the KV cache and compresses it to reduce the GPU memory that long-context decoding requires. Second, we evaluate FlashKV against vLLM by serving Llama-3-70B on one node with eight H100 GPUs (Table 2). FlashKV reduces KV-cache memory by 55% at 4k tokens and by 63% at 32k and 64k tokens. From 4k to 32k tokens, where both systems run, FlashKV speeds up decoding by 1.10x to 1.87x, and the speedup grows with context length. At 64k tokens, vLLM runs out of memory, while FlashKV still serves requests at that length.
