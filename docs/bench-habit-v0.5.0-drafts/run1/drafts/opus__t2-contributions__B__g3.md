This paper makes two contributions. First, we design and implement FlashKV, a runtime that pages and compresses the KV cache so that long-context requests fit in GPU memory. Second, we evaluate FlashKV against vLLM by serving Llama-3-70B on one node with eight H100 GPUs (Table 2). FlashKV cuts KV-cache memory by 55% at 4k tokens, and the reduction rises to 63% at 32k tokens. Its decoding speedup also grows with context length, from 1.10x at 4k tokens to 1.87x at 32k tokens. At 64k tokens, FlashKV still serves the model on the same node, where vLLM runs out of memory.
