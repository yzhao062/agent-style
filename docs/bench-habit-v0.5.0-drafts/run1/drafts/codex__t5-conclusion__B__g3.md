## Conclusion

We presented AdaptRL, which transfers grasping policies from simulation to a real robot by learning residual dynamics online. With 100 real-robot trials per category, AdaptRL outperforms both baselines across all five object categories (Table 5). Mean grasp success reaches 82.2%, exceeding DAgger by 19.2 percentage points and domain randomization by 36.2 percentage points. The largest gains over DAgger occur for reflective and transparent objects, the two categories with the lowest baseline success rates.
