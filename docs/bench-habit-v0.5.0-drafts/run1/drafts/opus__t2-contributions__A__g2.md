This paper makes two contributions. First, we design and implement FlashKV, a runtime that pages and compresses the KV cache for long-context LLM serving, so the same GPU memory holds more context. Second, we evaluate FlashKV against vLLM on Llama-3-70B, running on one node of eight H100 GPUs at context lengths from 4k to 64k tokens (Table 2). Across these lengths, FlashKV reduces KV-cache memory by 55% to 63%. Its decoding speedup over vLLM grows with context length, from 1.10× at 4k tokens to 1.87× at 32k tokens. At 64k tokens, vLLM runs out of memory, while FlashKV continues to serve requests.
