We introduce FlashKV, a runtime that combines KV-cache paging and compression for long-context LLM serving. On Llama-3-70B served by one 8×H100 node, FlashKV reduces KV-cache memory by 55% to 63% across 4k to 64k-token contexts (Table 2). Decoding speedup over vLLM increases with context length, reaching 1.87× at 32k tokens. FlashKV also serves 64k-token contexts on the same node, where vLLM runs out of memory.
