We introduce FlashKV, a runtime that pages and compresses the key-value (KV) cache for long-context large language model serving. On Llama-3-70B running on one node with eight H100 GPUs, FlashKV reduces KV-cache memory by 55% to 63% (Table 2). Across contexts where vLLM runs, decoding speedups increase with context length, reaching 1.87x at 32k tokens. FlashKV also serves 64k-token contexts on the same node, where vLLM runs out of memory.
