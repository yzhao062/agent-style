This paper makes two contributions. First, we present FlashKV, a runtime that pages and compresses the KV cache to serve long-context LLM requests. Second, we evaluate FlashKV against vLLM on Llama-3-70B running on one 8xH100 node (Table 2). From 4k to 32k tokens of context, FlashKV reduces KV-cache memory by 55% to 63% and speeds up decoding by 1.10x to 1.87x, with both gains growing as context lengthens. At 64k tokens, vLLM runs out of memory, while FlashKV continues to run.
