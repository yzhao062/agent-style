This paper contributes FlashKV, a runtime that pages and compresses the KV cache for long-context LLM serving, together with an evaluation against vLLM. Table 2 reports results for Llama-3-70B on one 8xH100 node at context lengths from 4k to 64k. At 4k to 32k contexts, where both systems run, FlashKV reduces KV-cache memory by 55% to 63%. Across these contexts, the decoding speedup over vLLM increases with context length, reaching 1.87x at 32k. On this node, FlashKV enables Llama-3-70B decoding at 64k context, where vLLM runs out of memory.
