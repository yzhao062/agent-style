We introduce FlashKV, a runtime that pages and compresses the KV cache for long-context LLM serving. Table 2 compares FlashKV with vLLM on Llama-3-70B using one 8xH100 node. From 4k to 32k context, FlashKV reduces KV-cache memory by 55% to 63% relative to vLLM. Its decoding speedup over vLLM grows with context length, from 1.10x at 4k to 1.87x at 32k. At 64k, vLLM runs out of memory, so no direct comparison is available at that length, but FlashKV completes decoding.
